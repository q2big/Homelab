# Homelab
A compact self-hosted homelab for game servers, web hosting, network-wide ad blocking and file storage. More to be added.

> **Note:** This README will be updated. The current projects are:

| Project | Description | Status |
| --- | --- | --- |
| [Network](network/VLAN.md) | Segmented UniFi network with [zone-based firewall](network/FIREWALL.md), [RADIUS Wi-Fi](network/WiFi.md) and [OpenVPN](network/OpenVPN.md) | Active |
| [NAS](nas/NAS.md) | Synology NAS with encrypted RAID 1, immutable snapshots and hardened access | Active |
| [Webserver](webserver/WEBSERVER.md) | Static websites on Docker Compose in the DMZ | In progress |
| [Kubernetes](kubernetes/KUBERNETES.md) | Talos Linux cluster on Proxmox with Flux GitOps | Paused |
| [Tooling](tools/TOOLING.md) | Podman toolbox with pinned infrastructure tools | Active |
